## 功能特性

- 自动发卡：商品分类、卡密库存管理、自动发货
- 分站系统：用户可开通自有分站店铺，数据按归属隔离
- 多模板支持：内置 XHY-01 等响应式模板，适配移动端与桌面端
- 聚合快捷登录：支持 QQ / 微信 / 支付宝 / 抖音 / 百度 / 微博 六种登录方式
- 在线升级：后台一键检测新版本并自动升级，升级前自动备份
- 数据大屏：销售额、订单量、访问量等核心指标与趋势图表
- 支付接入：支付宝 / 微信 / QQ 钱包 / 易支付等常用支付方式
- 风控与安全：防 CC 攻击、验证码、登录限制等内置防护

## 环境要求

- PHP 7.4 及以上（推荐 8.x）
- MySQL 5.6 及以上
- Nginx / Apache Web 服务

## 安装步骤

1. 将本仓库源码上传至网站根目录
2. 访问 `http://你的域名/install/` 进入安装向导
3. 按提示填写数据库信息与管理员账号，完成安装
4. 登录后台 `http://你的域名/admin/` 进行商品与系统配置
